开发者为什么选择 Keel

本地 Web 环境所需的一切，无需再照看容器。

原生运行，没有容器

Keel 下载真正的二进制文件并直接运行。没有 Docker Desktop，没有虚拟机，不用等待镜像，打开项目时风扇也不会狂转。

向导一步到位

选择初始技术栈：Web 与全栈、现代 JS 与 API，或最小 / 自定义，Keel 会一次性装好并配置完成。

不留任何残余

软件包、配置和数据都在 Keel 自己的文件夹里，与 Homebrew 和系统 PATH 互不干扰。卸载 Keel 后不会留下任何东西。

.test 上的真实 HTTPS

新建站点时，虚拟主机、由 Keel 自带 CA 签发的本地证书以及 hosts 条目，一个表单全部搞定。

多版本并存

同时运行多个 PHP 版本，可视化编辑 php.ini 和扩展，按站点切换。

终端同样适用

将 Keel 加入 PATH，即可在任意终端使用 php、node、composer、mysql，版本与站点所用的一致。

分享本地站点

通过 Cloudflare Tunnel、bore、chisel、frp 或 rathole 公开站点，无需离开应用。

拦截所有邮件

Mailpit 会接收应用发出的邮件，测试邮件不会进入真实收件箱。

支持你的语言

支持 20 种语言，兼容 VoiceOver 等屏幕阅读器，可完全用键盘操作，并遵循“减少动态效果”设置。

常见问题

Keel 真的免费吗？

是的，个人和商业本地开发均可免费使用。Keel 由一个人开发；如果它帮你节省了时间，可以在应用内或项目页面打赏。

需要安装 Docker 吗？

不需要。Keel 直接在你的电脑上运行各个服务器和数据库的原生版本。

会和 Homebrew 或系统自带的 PHP 冲突吗？

不会。Keel 安装的所有内容都在它自己的文件夹里。只有在“设置”中将 Keel 加入 PATH 后，终端才会使用 Keel 的版本。

数据存放在哪里？如何彻底卸载 Keel？

删除应用，再删除这个文件夹：

  • macOS: ~/Library/Application Support/Keel/
  • Windows: %APPDATA%\com.keel.app\
  • Linux: ~/.local/share/com.keel.app/
如何更新？

Keel 会在后台检查新版本，并在重启时安装经过签名的更新。你也可以在“设置 → 应用”中手动检查。
