Docker 없는 로컬 개발 환경.

PHP, Node.js, Caddy, Nginx, Apache, MariaDB, PostgreSQL, Redis를 비롯한 수십 가지 도구를 클릭 한 번으로 네이티브 설치합니다. HTTPS 사이트, 터널, 개발용 메일까지 한 앱에서 다룹니다. Keel을 지우면 시스템은 설치 전 그대로입니다.

Keel 다운로드 기능 살펴보기

macOS, Windows, Linux 무료. 최신 버전 1.0.2, 서명된 자동 업데이트를 지원합니다.

개발자들이 Keel로 옮기는 이유

로컬 웹 개발에 필요한 모든 것을, 신경 쓸 컨테이너 없이.

컨테이너가 아닌 네이티브

Keel은 실제 바이너리를 내려받아 바로 실행합니다. Docker Desktop도, VM도, 이미지 대기도 없고, 프로젝트를 열 때 팬이 요란하게 돌지도 않습니다.

마법사 하나로 준비 완료

초기 스택을 Web & Full Stack, Modern JS & API, 최소 / 사용자 지정 중에서 고르면 Keel이 한 번에 설치하고 구성합니다.

흔적을 남기지 않음

패키지, 설정, 데이터는 Homebrew와 시스템 PATH와는 별개로 Keel 전용 폴더에 저장됩니다. Keel을 삭제하면 아무것도 남지 않습니다.

.test에서 진짜 HTTPS

사이트를 만들면 가상 호스트, Keel 자체 CA의 로컬 인증서, hosts 항목이 양식 하나로 만들어집니다.

여러 버전을 나란히

여러 PHP 버전을 함께 실행하고, php.ini와 확장을 화면에서 편집하며, 사이트별로 전환합니다.

터미널에서도 그대로

Keel을 PATH에 추가하면 어느 터미널에서든 php, node, composer, mysql을 사이트와 같은 버전으로 쓸 수 있습니다.

로컬 사이트 공유

앱을 떠나지 않고 Cloudflare Tunnel, bore, chisel, frp, rathole로 사이트를 외부에 공개합니다.

모든 메일을 받아내기

Mailpit이 앱에서 보낸 메일을 받아 주므로 테스트 메일이 실제 받은편지함에 도달하지 않습니다.

내 언어로 사용

20개 언어, VoiceOver 등 스크린 리더 지원, 완전한 키보드 탐색, 동작 줄이기 설정 존중.

선택 패키지는 공식 배포처에서 내려받으며 라이선스는 각 제작자에게 있습니다.

자주 묻는 질문

Keel은 정말 무료인가요?

네, 개인 및 상업용 로컬 개발에 무료입니다. Keel은 한 사람이 만들고 있으며, 도움이 되었다면 앱이나 프로젝트 페이지에서 후원할 수 있습니다.

Docker가 필요한가요?

아니요. Keel은 각 서버와 데이터베이스의 네이티브 빌드를 컴퓨터에서 직접 실행합니다.

Homebrew나 시스템 PHP와 충돌하지 않나요?

충돌하지 않습니다. Keel이 설치하는 모든 것은 전용 폴더에 있습니다. 설정에서 Keel을 PATH에 추가해야만 터미널에서 Keel의 버전이 보입니다.

데이터는 어디에 있고, Keel을 완전히 제거하려면 어떻게 하나요?

앱을 삭제한 다음 이 폴더를 삭제하세요.

  • macOS: ~/Library/Application Support/Keel/
  • Windows: %APPDATA%\com.keel.app\
  • Linux: ~/.local/share/com.keel.app/
업데이트는 어떻게 되나요?

Keel이 백그라운드에서 새 버전을 확인하고, 다시 시작할 때 서명된 업데이트를 설치합니다. 설정 → 애플리케이션에서 직접 확인할 수도 있습니다.
