Questions

Is Keel really free?

Yes, for personal and commercial local development. Keel is built by one person; if it saves you time, you can tip from the app or the project page.

Do I need Docker?

No. Keel runs native builds of each server and database directly on your machine.

Will it clash with Homebrew or my system PHP?

No. Everything Keel installs lives in its own folder. Your terminal only sees Keel's versions if you choose to add Keel to PATH in Settings.

Where is my data, and how do I remove Keel completely?

Delete the app, then this folder:

  • macOS: ~/Library/Application Support/Keel/
  • Windows: %APPDATA%\com.keel.app\
  • Linux: ~/.local/share/com.keel.app/
How do updates work?

Keel checks for new versions in the background and installs signed updates when you restart it. You can also check in Settings → Application.
