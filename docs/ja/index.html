Dockerなしで、ローカル開発環境を。

PHP、Node.js、Caddy、Nginx、Apache、MariaDB、PostgreSQL、Redisをはじめ、数十種類のツールをワンクリックでネイティブにインストール。HTTPS対応のサイト、トンネル、開発用メールも同じアプリで扱えます。Keelを削除すれば、システムは元の状態に戻ります。

Keelをダウンロード 機能を見る

macOS・Windows・Linux向けに無料。最新バージョンは 1.0.2、署名付きの自動アップデートに対応しています。

開発者がKeelに乗り換える理由

ローカルのWeb開発環境に必要なものをすべて、面倒なコンテナ管理なしで。

コンテナではなくネイティブ

Keelは本物のバイナリをダウンロードして直接実行します。Docker Desktopも、VMも、イメージの待ち時間も不要。プロジェクトを開いてもファンが回り出しません。

ウィザードひとつで準備完了

初期スタックを Web & Full Stack、Modern JS & API、最小 / カスタムから選ぶだけで、Keelがインストールから設定までを一度に行います。

後に何も残さない

パッケージ、設定、データはKeel専用のフォルダに置かれ、Homebrewやシステムの PATH には影響しません。Keelをアンインストールすれば、何も残りません。

.test で本物のHTTPS

サイトを作成すると、バーチャルホスト、Keel独自のCAによるローカル証明書、hostsファイルのエントリが、ひとつのフォームからまとめて用意されます。

複数バージョンを並行して利用

複数のPHPバージョンを同時に使え、php.ini や拡張機能も画面上で編集できます。サイトごとの切り替えも可能です。

ターミナルでもそのまま

KeelをPATHに追加すれば、どのターミナルでも php、node、composer、mysql が使えます。サイトと同じバージョンです。

ローカルサイトを共有

Cloudflare Tunnel、bore、chisel、frp、ratholeでサイトを公開できます。アプリから離れる必要はありません。

メールをすべてキャッチ

Mailpitがアプリの送信メールを受け取るので、テストメールが実際の受信箱に届くことはありません。

日本語にも対応

20言語に対応。VoiceOverなどのスクリーンリーダーやキーボードだけの操作も利用でき、視差効果を減らす設定にも従います。

よくある質問

Keelは本当に無料ですか？

はい。個人開発・商用開発を問わず、ローカル開発には無料です。Keelは一人で開発しています。役に立ったら、アプリまたはプロジェクトページからチップで応援していただけると嬉しいです。

Dockerは必要ですか？

いいえ。Keelは各サーバーとデータベースのネイティブビルドを、お使いのマシン上で直接実行します。

HomebrewやシステムのPHPと衝突しませんか？

しません。Keelがインストールするものはすべて専用のフォルダに置かれます。設定でKeelをPATHに追加しない限り、ターミナルにKeelのバージョンが見えることはありません。

データはどこにありますか？ Keelを完全に削除するには？

アプリを削除し、続けて次のフォルダを削除してください。

  • macOS: ~/Library/Application Support/Keel/
  • Windows: %APPDATA%\com.keel.app\
  • Linux: ~/.local/share/com.keel.app/
アップデートはどのように行われますか？

Keelはバックグラウンドで新しいバージョンを確認し、再起動時に署名付きアップデートをインストールします。設定 → アプリケーションから手動で確認することもできます。
